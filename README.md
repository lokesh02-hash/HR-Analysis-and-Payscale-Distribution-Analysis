# HR-Analysis-and-Payscale-Distribution-Analysis

## Overview

This project is an interactive HR & Payroll Analytics Dashboard built using Power BI, Excel, Power Query, and DAX. It analyzes employee attendance, payroll distribution, overtime trends, leave behavior, and department-wise workforce performance through dynamic visualizations and KPI reporting.

The dashboard simulates a real corporate HR analytics environment and focuses on transforming raw attendance and payroll data into meaningful business insights.

---

## Features

* Payroll & Salary Analysis
* Attendance & Leave Tracking
* Department-wise Workforce Insights
* Salary Distribution Analysis
* Overtime & WFH Monitoring
* Interactive KPI Dashboard
* Dynamic Filters & Slicers
* Employee-level Reporting
* Business Intelligence Storytelling

---

## KPIs Included

* Total Payroll Cost
* Average Salary
* Attendance %
* WFH %
* Sick Leave %
* Overtime Hours
* Total Employees

---

## Tools & Technologies

* Power BI
* DAX
* Power Query
* Microsoft Excel

---

## Dashboard Insights

The dashboard helps analyze:

* Payroll trends across departments
* Attendance behavior and leave patterns
* Workforce productivity
* Salary allocation and overtime impact
* Employee performance indicators

---

## Project Workflow

1. Data Collection using Excel
2. Data Cleaning with Power Query
3. Data Modeling in Power BI
4. DAX Measures & Calculations
5. Dashboard Design & Visualization
6. Interactive Reporting & Insights
